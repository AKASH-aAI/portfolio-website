HR Analytics & Employee Attrition Prediction System

An end-to-end HR analytics project that analyzes employee attrition patterns and predicts turnover using SQL, Python, Power BI, machine learning, and a Streamlit app.

Live Demo GitHub

Business Problems

Employee attrition carries significant cost and operational impact. This project looks at the factors behind attrition and builds a predictive model to support earlier intervention.

  • Recruitment and training costs
  • Employee retention
  • Satisfaction and performance
  • Workload management
  • Salary-related attrition patterns
  • Workforce planning

Analytical Workflow

SQL Cleaning→ EDA→ Visualization→ Power BI→ ML Modeling→ Streamlit App

Key Analysis

  • SQL data cleaning and validation
  • Attrition distribution
  • Satisfaction analysis
  • Salary analysis
  • Department analysis
  • Employee tenure
  • Workload analysis
  • Correlation analysis
  • Attrition driver identification

Model Comparison — Reported Results

These are reported model evaluation results from the project. They should not be interpreted as guarantees of employee retention or as the sole basis for employment decisions.
