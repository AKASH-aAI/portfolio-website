AI Career Coach

An ML and generative AI-powered application that predicts a suitable IT career based on user interests and strengths, then generates a personalized learning roadmap.

Live Demo GitHub

Password-protected application — request access via email.

Problem Statement

Choosing an IT career path is difficult when you have multiple interests. Many people need clarity on which role suits them best and a practical roadmap to reach it. This application combines ML career prediction with an AI-generated learning roadmap.

Workflow

User Input→ ML Career Prediction→ Career Match Result→ Gemini Roadmap

Features

  • IT career prediction
  • Career match percentage
  • AI-generated career roadmap
  • Learning path suggestions
  • Project and certification suggestions
  • Interview preparation guidance
  • Password-protected application

Supported Career Categories

Software Engineer Data Analyst Data Scientist Machine Learning Engineer AI Researcher Product Manager Cybersecurity Analyst UI/UX Designer Business Analyst Cloud Engineer

Dataset & Model

  • 3,000 records
  • 10 career categories
  • 15 career-related input attributes
  • Reported model accuracy: approximately 90%

The 90% accuracy is a reported evaluation result, not a guarantee of career suitability.
