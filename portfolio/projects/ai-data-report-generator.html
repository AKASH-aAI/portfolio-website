AI Data Report Generator

An automated dataset analytics platform that transforms raw CSV files into professional data quality reports — profiling, quality checks, outlier detection, and PDF output.

Live Demo GitHub Sample Report

Password-protected demo — request access via email.

Problem Statement

Manual exploratory data analysis and data-quality reporting can take a significant amount of time on every new dataset. Analysts repeatedly check for missing values, duplicates, and outliers, and then write up findings manually. This application automates that workflow into a single upload-and-download report.

Workflow

CSV Upload→ Dataset Profiling→ Quality Checks→ Outlier Analysis→ Health Score→ PDF Report

Features

  • CSV dataset upload
  • Automated dataset profiling
  • Missing value detection
  • Duplicate row detection
  • Outlier detection
  • Dataset health score
  • Column-wise analysis
  • Numeric statistics (mean, median, standard deviation)
  • Memory usage analysis
  • Professional PDF report generation
